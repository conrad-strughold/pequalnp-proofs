# Strategy and verification

Run python3 swarm/client.py plan PROJECT_ID with the administrator token. This creates eligible tasks from a deterministic six-stage workflow. Re-run after accepted results to unlock the next stage. Existing titles prevent duplicates within a project. No language model or paid service is necessary. This is a conservative planning baseline, not autonomous scientific reasoning.

Structural evidence checks do not demonstrate truth. Human review remains mandatory. Future discipline-specific verifiers must be trusted, isolated, versioned and tested. Never execute contributor-supplied code in the server process.
